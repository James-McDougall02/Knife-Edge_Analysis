Run raw_data.py to analyse csv files of micropillar cavity photoluminescence. This will generate a plot of how the intensity of the fundamental mode of the cavity changes as the knife edge is scanned through the Fourier image. This represents the integral of the input signal. Fitting an error function to this data allows you to determine the width of the input light, in this case the width of the emission in the Fourier plane. Using this width, the NA of the emission is determined by calculating the fraction of the Fourier image (NA=0.7 for our objective) that the emission takes up. E.g., if the radius of the emission (1/e^2) is 140um and the image is r=280um, the NA will be 140/280=0.5. These plots are saved to the folder which should be the size of the pillars analysed, e.g. 200 / 225 etc. The analysis of each pillar file (usually 3 per pillar ID) is saved to a master csv file: Folder,	Pillar ID,	Pillar diameter,	Fitted ERF Width (um),	ERF Width Error (um),	Fitted NA,	NA Error,	Pillar Amplitude,	Pillar Wavelength (nm),	Pillar Cavity Width (nm),	Mode Peaks Found. 

To analyse the results from multiple pillars of one diameter, run single_diam.py. This analyses the master csv file and creates a new file in the same location, this time with the averaged results per pillar (usually 3 measurements). It then plots: NA of each pillar vs diameter (should all be the same diameter), NA as a histogram with bin widths of 0.02, and NA vs individual pillar ID. It saves these plots as .png files to the same directory.

To analyse the results of multiple pillars of multiple diameters, first make a csv file of the form: '{month}_avg_multi_master_pillar_results.csv' and save it in the month, e.g. '...LG05-ExperimentalData\KnifeEdge\2611' with all the averaged pillar results. This file will then plot each averaged pillar NA vs pillar diameter, and overlays an average for each diameter with +- one s.d..
